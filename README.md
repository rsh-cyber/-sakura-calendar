# Sakura 日历感知

让 Sakura 角色记得节日、纪念日和日常事项，并在合适的时间主动开口。

日历感知为每个角色保存独立的事件与节日设置。插件判断触发时间和发送状态，角色根据事件内容组织祝福、提醒或感想。

当前版本 **1.0.0**，插件 ID 为 `sakura.calendar`，作者署名为 **rsh**。

## 功能

- **三类事件**。每日、年度、自定义事件分别启用，也可逐条停用、编辑或删除。
- **中日节日**。中国 23 项、日本 29 项，按国家选择，每个节日单独勾选。
- **角色绑定**。各角色拥有独立的开关、时区、事件和节日偏好，切换角色时管理页自动更新。
- **定时提醒窗口**。所有每日事件及指定时间的自定义事件，按当地时间前后各 10 分钟判断是否发起。
- **启动次数与去重**。记录当天 Sakura 启动次数，同角色、同事件当天成功提醒后不重复发送。
- **可视化管理**。通过本机浏览器中的表单和日期选择器配置事件。

## 运行环境

| 项目 | 要求或验收范围 |
|---|---|
| 操作系统 | Windows x64 |
| 插件接口 | Sakura Plugin API 4 |
| 完整隔离验收使用的宿主 | Sakura 1.3.6 |
| 角色回复 | 使用 Sakura 已配置的对话模型 |

日期计算、事件管理和去重使用本地逻辑及内置日期表。角色主动发话沿用宿主的模型服务，响应速度取决于模型生成与宿主队列。插件运行所需 Python 由 Sakura 提供。

## 安装与启用

1. 从本仓库的 Releases 页面下载 `sakura.calendar-1.0.0.zip`。
2. 打开 Sakura 的「设置 → 插件 → 更多 → 从 ZIP 安装…」，选择下载的 ZIP。
3. 在「已安装」中启用「日历感知」。
4. 切换到要配置的角色，打开插件的「管理日历事件」。
5. 开启该角色的日历总开关，再开启所需事件类别或选择节日。

新角色的日历默认关闭。节日提醒由日历总开关、当前国家和逐项勾选共同控制。

已有同 ID 插件时，可通过宿主重新导入 ZIP 更新。升级会保留事件 ID、角色设置和提醒记录。较早版本的共用设置与回执，会一次性归给升级后首先识别到的角色。

## 三类事件

| 类型 | 配置内容 | 提醒规则 |
|---|---|---|
| 每日事件 | 具体时间、描述 | 每天在指定时间前后 10 分钟内，符合空闲条件时提醒一次 |
| 年度事件 | 从日历选择月日，填写日子名称与意义 | 每年在该日符合空闲条件时提醒一次 |
| 自定义事件 | 具体日期或「每日」，具体时间或「任意时间」，名称选填、描述必填 | 指定时间使用前后 10 分钟窗口；任意时间在当天符合空闲条件时提醒一次 |

例如，可以添加每天 14:00 的「起来活动一下」、每年固定月日的「相识纪念日」，或某个日期的「带上文件」。

### 时间窗口

12:00 的每日或定时自定义事件，可以在 **11:50:00–12:10:00** 发起，两个边界都包含。12:10:01 开始跳过，15:00 打开 Sakura 也会跳过这条午间提醒。

窗口约束提醒的发起时间，模型生成和宿主排队可能使回复稍晚出现。窗口只在事件的当地日期内生效。

新增年度事件按日期触发。为兼容旧数据，已有明确触发时刻的年度事件保留原时刻及当天补提醒行为。

### 预设问候与用户事件

预设的早安、午安、晚安在当天首次启动期间按各自时间窗口判断。用户填写了描述的每日事件，在后续启动时仍可于窗口内提醒。年度提醒完成后，后续到时的每日事件也会继续判断。

## 节日提醒

选择「关闭」「中国」或「日本」，再勾选希望角色记得的日子。同一时间启用一个国家，切换后保留各国原来的勾选。

## 时区、角色与去重

时区支持北京、东京和跟随 Windows 时间，按每个角色的设置独立判断当地日期。

Sakura 当天首次启动计为 1，之后实际重启递增。保存设置、插件重载和切换角色沿用原次数。跨到新一天时从 1 开始，应用持续运行过午夜也会自动切换日期。

提醒按角色、当地日期、事件类别和事件 ID 去重。明确失败的任务可在 60 秒后重试，重试仍受时间窗口约束。回执不明确时，该事件当天暂停重发。新日期使用新的一组提醒状态。

事件配置与提醒记录保存在本机插件数据目录。触发主动回合时，相关事件内容会随角色对话提交给宿主选定的模型。管理页通过本机回环地址访问。

## 常见情况

**导入后没有提醒**

检查插件是否启用、当前角色的日历总开关是否开启、相应事件类别或节日是否选择，以及是否处于时间窗口和空闲状态。切换角色后应核对新角色自己的设置。

**错过时间窗口**

每日和定时自定义事件在窗口结束后自动跳过。需要当天空闲时提醒的自定义事项，可以选择「任意时间」。

**设置页的启动次数显示「—」**

插件无法确认 Sakura 应用启动身份时，主动问候会暂停。常规安装应从 Sakura 桌面程序启动。

**聊天里出现「（日历问候）」**

这是插件触发角色主动回合时的简短标记。私有上下文会引导角色以自己想起事项的口吻表达。
